# SiteChat — Full-Stack Site Coordination Platform (Assessment 3)

/frontend — React 18 + Vite SPA (see frontend/README.md)
/backend  — Node.js/Express REST API + SQLite database (see backend/README.md)

## Run locally
1. `cd backend && npm install && npm run seed && npm start`   (http://localhost:4000)
2. `cd frontend && npm install && npm run dev`                 (http://localhost:5173)
